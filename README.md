## Typing Gladiator ⚔️⌨️

A fast-paced typing game designed to improve typing speed and coding muscle memory.

**How it works:**
- Words and real programming keywords fall from the top
- Type them correctly to destroy them before they hit the bottom
- Progressive difficulty (easy → medium → hard terms)
- Live stats: Score, Level, Streak, WPM, Accuracy
- Combo system and particle effects

**How to play:**
1. Open `typing-gladiator.html` in any modern browser
2. Click **Enter the Arena**
3. Just start typing — no mouse needed

---

## Tech Stack

- Pure HTML + CSS + JavaScript
- No frameworks or dependencies
- Runs entirely in the browser
